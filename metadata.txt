name=ICESat-2 Data Explorer
description=Access and analyze ICESat-2 ATL03, ATL08, ATL13 and ATL24 data in QGIS with interactive profiles, provenance reports and optional model-tide values.
about=ICESat-2 Data Explorer provides multi-product ICESat-2 access through SlideRule, interactive RGT/cycle/beam profiles, reproducible GeoPackage and HTML outputs, robust large-area ATL03 batching, and optional GOT4.10c ocean-tide evaluation through pyTMD. External Python dependencies are installed on demand into plugin-managed storage: SlideRule Python client 5.5.0 for data access and, optionally, pyTMD 3.0.9 plus its isolated tide environment. GOT4.10c is downloaded at runtime and is not bundled. Requires QGIS 3.44 or later; QGIS 3.44 LTR on Windows has been functionally validated. QGIS 3.30 is not supported for automatic dependency setup. Unlike satellite-derived-bathymetry raster/ML plugins, this plugin focuses on direct ICESat-2 ATL03/ATL08/ATL13/ATL24 access, inspection, profiling, provenance reporting and tide-aware analysis.
