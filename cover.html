ICESat-2 Data Explorer

User Manual · Version 0.10.3
Authors: Laura Coelho de Andrade; Kim Earle Lowell; Nilcilene das Graças Medeiros; Arthur Amaral e Silva; Italo Oliveira Ferreira.
Recommended citation: Andrade et al. (2026), ICESat-2 Data Explorer.

Supported products

ATL03, ATL08, ATL13, and ATL24 workflows are available directly inside QGIS.

Main tools

Data Explorer, HDF5 Converter, Interactive Profile, and Model Tide Values.

Version highlight

Version 0.10.3 combines the Windows HDF5 hotfix with clearer AOI selection, ATL24 class choices, predictable output names, and CRS-safe layer zoom.

Quick start

  1. Install the plugin from ZIP in QGIS.
  2. Open Data Explorer and install download support once.
  3. Use HDF5 Converter to export local NASA granules to GeoPackage or CSV.
  4. Review the generated HTML reports and optional profile/tide tools inside QGIS.
